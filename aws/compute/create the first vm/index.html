    Create the first VM

    การสร้าง Virtual Machine (VM) หรือ Instance เครื่องแรกใน AWS (Amazon Web Services) ทำได้ง่ายโดยใช้บริการ Amazon EC2 (Elastic Compute Cloud) นี่คือขั้นตอนการสร้าง VM อย่างละเอียด:

    ขั้นตอนการสร้าง VM เครื่องแรกใน AWS

    1. เข้าสู่ระบบ AWS Management Console

    2. เข้าไปที่ AWS Console และล็อกอินเข้าสู่บัญชี AWS ของคุณ

    3. เปิดบริการ Amazon EC2

    4. ในหน้า Console ให้ค้นหา "EC2" จากแถบค้นหา และเลือก EC2 เพื่อเข้าสู่หน้าจัดการบริการ EC2

    5. เลือก Launch Instance

    6. ในหน้า EC2 Dashboard ให้คลิกที่ปุ่ม Launch Instance เพื่อเริ่มต้นการสร้าง VM

    7. ตั้งชื่อและเลือก AMI (Amazon Machine Image)

    8. ตั้งชื่อ Instance ตามที่ต้องการ

    9. เลือก Amazon Machine Image (AMI) หรือระบบปฏิบัติการที่ต้องการ เช่น Amazon Linux 2, Ubuntu, หรือ Windows Server

    10. เลือกประเภทของ Instance (Instance Type)

    11. เลือกขนาดและประเภทของ Instance ที่เหมาะสม เช่น t2.micro สำหรับ Free Tier (มีสิทธิ์ใช้ฟรี 750 ชั่วโมงต่อเดือน) หรือขนาดอื่นๆ ตามความต้องการของระบบ

    12. ตั้งค่าคีย์คู่ (Key Pair)

    13. เลือกสร้าง Key Pair เพื่อใช้เข้าถึง Instance ผ่าน SSH (สำหรับ Linux) หรือ RDP (สำหรับ Windows)

    14. ดาวน์โหลดไฟล์ .pem ที่ได้มาและเก็บรักษาไว้ให้ปลอดภัย

    15. กำหนดการตั้งค่าเครือข่าย (Network Settings)

    16. เลือก VPC (Virtual Private Cloud) และ Subnet ที่ต้องการใช้
    17. กำหนด Auto-assign Public IP ให้เป็น Enabled หากต้องการให้ Instance สามารถเข้าถึงได้จากอินเทอร์เน็ต

    18. กำหนด Security Group เพื่อเปิดพอร์ตที่ต้องการ เช่น พอร์ต 22 สำหรับ SSH (Linux) หรือพอร์ต 3389 สำหรับ RDP (Windows)

    19. ตั้งค่าพื้นที่เก็บข้อมูล (Storage)

    20. ระบุขนาดของ EBS Volume (เช่น 8GB) สำหรับ Root Volume ของ Instance

    21. เลือกประเภทของ Storage เช่น General Purpose SSD (gp2) สำหรับการใช้งานทั่วไป

    22. ตรวจสอบการตั้งค่าและ Launch Instance

    23. ตรวจสอบการตั้งค่าทั้งหมดให้ถูกต้อง

    24. คลิก Launch Instance เพื่อเริ่มต้นสร้าง VM ของคุณ

    25. การตรวจสอบสถานะและการเชื่อมต่อเข้า VM

      • หลังจาก Instance ถูกสร้างแล้ว ให้รอสักครู่จนสถานะเปลี่ยนเป็น Running
      • ตรวจสอบ Public IP Address หรือ Public DNS ที่ใช้ในการเชื่อมต่อเข้าไปยัง VM

      • ใช้ SSH (สำหรับ Linux) หรือ RDP (สำหรับ Windows) เพื่อเชื่อมต่อเข้าไปยัง VM โดยใช้ Key Pair ที่สร้างไว้

      • ตัวอย่างคำสั่ง SSH สำหรับ Linux: bash ssh -i /path/to/your-key.pem ec2-user@your-public-ip

      • สำหรับ Windows, ใช้โปรแกรม Remote Desktop Connection โดยนำ Public IP ใส่และใช้ไฟล์ .pem เพื่อถอดรหัสข้อมูลสำหรับล็อกอิน

    สรุป

    เพียงทำตามขั้นตอนด้านบน คุณก็จะสามารถสร้างและใช้งาน VM เครื่องแรกใน AWS ได้เรียบร้อย
