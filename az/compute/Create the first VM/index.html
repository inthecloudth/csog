    Create the first VM

    การสร้าง Virtual Machine (VM) ใน Microsoft Azure ทำได้ง่ายโดยใช้บริการ Azure Virtual Machines ขั้นตอนในการสร้าง VM บน Azure มีดังนี้:

    ขั้นตอนการสร้าง VM เครื่องแรกใน Azure

    1. เข้าสู่ระบบ Azure Portal

    2. เข้าไปที่ Azure Portal และลงชื่อเข้าใช้บัญชี Azure ของคุณ

    3. เปิดบริการ Virtual Machines

    4. ในหน้า Azure Portal ให้ค้นหา "Virtual Machines" จากแถบค้นหา แล้วเลือก Virtual Machines เพื่อเข้าสู่หน้า Virtual Machine Dashboard

    5. เริ่มสร้าง Virtual Machine ใหม่

    6. คลิกปุ่ม + Create > Azure virtual machine เพื่อเริ่มสร้าง VM ใหม่

    7. ตั้งค่าข้อมูลพื้นฐาน (Basics)

    8. Subscription: เลือก Subscription ที่ต้องการใช้
    9. Resource Group: เลือก Resource Group ที่มีอยู่หรือสร้าง Resource Group ใหม่เพื่อจัดกลุ่มทรัพยากรที่เกี่ยวข้อง
    10. Virtual Machine Name: ตั้งชื่อ VM ของคุณตามที่ต้องการ
    11. Region: เลือก Region ที่ VM ของคุณจะถูกสร้าง เช่น East US หรือ Southeast Asia

    12. Availability Options: เลือก Availability zone หรือ Availability set หากต้องการเพิ่มความพร้อมในการใช้งาน

    13. เลือก Image (ระบบปฏิบัติการ)

    14. เลือกระบบปฏิบัติการที่ต้องการใช้ เช่น Windows Server, Ubuntu, Red Hat Enterprise Linux ฯลฯ

    15. เลือก Size (ขนาดของ VM)

    16. เลือกขนาด VM ตามความต้องการ เช่น Standard B1s หรือ Standard D2s_v3 ขึ้นอยู่กับการใช้งานและงบประมาณของคุณ

    17. สามารถดูรายละเอียดค่าใช้จ่ายของแต่ละขนาดได้ในหน้าต่างนี้

    18. ตั้งค่าการรับรองความปลอดภัย (Administrator Account)

    19. กำหนดชื่อผู้ใช้และรหัสผ่านสำหรับการเชื่อมต่อไปยัง VM (สำหรับ Windows) หรือใช้ SSH public key สำหรับการเข้าถึง (สำหรับ Linux)

    20. ตั้งค่า Inbound Port Rules (Firewall)

    21. เลือกเปิด RDP (พอร์ต 3389) สำหรับการเข้าถึง Windows VM หรือ SSH (พอร์ต 22) สำหรับ Linux VM

    22. สามารถเพิ่มพอร์ตเพิ่มเติมได้ตามความต้องการ

    23. ตั้งค่าดิสก์ (Disks)

    24. เลือกประเภทของดิสก์สำหรับระบบปฏิบัติการ เช่น Standard SSD, Premium SSD หรือ HDD

    25. สามารถเพิ่ม Data Disk เพิ่มเติมได้หากต้องการพื้นที่เก็บข้อมูลเพิ่ม

    26. ตั้งค่าเครือข่าย (Networking)

      • Azure จะสร้าง Virtual Network (VNet) และ Subnet ให้โดยอัตโนมัติ หากคุณไม่มีอยู่แล้ว
      • กำหนด Public IP Address เพื่อให้ VM สามารถเข้าถึงได้จากอินเทอร์เน็ต (สามารถปิดได้หากไม่ต้องการให้เข้าถึงจากภายนอก)
      • เลือก Network Security Group (NSG) เพื่อควบคุมการรับส่งข้อมูลที่เข้าสู่ VM

    27. การตั้งค่าเพิ่มเติม (Management, Monitoring)

      • คุณสามารถตั้งค่าการ Monitoring เช่น การเปิดใช้งาน Boot diagnostics หรือการตั้งค่า Auto-shutdown ได้ในส่วนนี้

    28. ตรวจสอบและสร้าง VM

      • ตรวจสอบข้อมูลทั้งหมดอีกครั้งเพื่อความถูกต้อง
      • คลิก Review + create และคลิก Create เพื่อเริ่มการสร้าง VM

    29. รอการสร้าง VM

      • หลังจากการสร้างเสร็จสมบูรณ์ คุณสามารถตรวจสอบสถานะของ VM ได้ในหน้า Virtual Machines ของ Azure Portal

    30. เชื่อมต่อกับ VM

      • เมื่อ VM อยู่ในสถานะ Running คุณสามารถคลิกที่ VM และเลือก Connect
      • สำหรับ Windows VM ให้เลือก RDP และดาวน์โหลดไฟล์ .rdp เพื่อล็อกอิน
      • สำหรับ Linux VM ใช้คำสั่ง SSH ใน Terminal หรือใช้ SSH client

    สรุป

    การสร้าง VM ใน Azure ใช้เวลาไม่นานและสามารถปรับแต่งการตั้งค่าได้หลากหลาย เช่น ระบบปฏิบัติการ ขนาดของ VM และการตั้งค่าเครือข่าย เพียงทำตามขั้นตอนด้านบน คุณก็จะมี VM เครื่องแรกใน Azure พร้อมใช้งาน
