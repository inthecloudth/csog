    Create the first vm

    การสร้าง Virtual Machine (VM) บน Google Cloud Platform (GCP) ใช้บริการ Google Compute Engine ซึ่งเป็นบริการคล้ายกับ Amazon EC2 บน AWS นี่คือขั้นตอนการสร้าง VM เครื่องแรกใน GCP:

    ขั้นตอนการสร้าง VM เครื่องแรกใน GCP

    1. เข้าสู่ระบบ Google Cloud Console

    2. ไปที่ Google Cloud Console และลงชื่อเข้าใช้บัญชี Google ของคุณ

    3. เปิดบริการ Compute Engine

    4. ในหน้า Console ให้ค้นหา "Compute Engine" จากแถบค้นหา และเลือก Compute Engine > VM instances

    5. เริ่มสร้าง Instance ใหม่

    6. ในหน้า VM instances ให้คลิกปุ่ม Create Instance เพื่อเริ่มการสร้าง VM ใหม่

    7. ตั้งชื่อและเลือก Region/Zone

    8. ตั้งชื่อ Instance Name ตามที่ต้องการ

    9. เลือก Region และ Zone ที่คุณต้องการให้ VM ของคุณอยู่ เช่น us-central1 หรือ asia-southeast1 ขึ้นอยู่กับที่ตั้งทางภูมิศาสตร์ที่ต้องการ

    10. เลือก Machine Configuration

    11. เลือกประเภทของ Machine Family เช่น General-purpose สำหรับการใช้งานทั่วไป

    12. เลือกขนาดของ VM เช่น e2-micro (ซึ่งเป็นประเภทที่อยู่ใน Free Tier) หรือขนาดอื่นๆ ตามความต้องการ

    13. เลือก Boot Disk

    14. เลือกระบบปฏิบัติการที่ต้องการจาก Boot disk เช่น Debian, Ubuntu, หรือ Windows Server

    15. สามารถปรับขนาดและประเภทของดิสก์ได้ เช่น Standard persistent disk หรือ SSD persistent disk

    16. ตั้งค่า Firewall และเครือข่าย

    17. เลือก Network ที่ต้องการใช้ เช่น default network
    18. เลือกเปิด Allow HTTP traffic และ Allow HTTPS traffic หากคุณต้องการให้ VM สามารถรับทราฟฟิกจากอินเทอร์เน็ตได้

    19. หากต้องการให้ VM มีการเชื่อมต่อจากอินเทอร์เน็ต ให้เปิด External IP ในค่า Ephemeral

    20. สร้างและตรวจสอบการตั้งค่าเพิ่มเติม (ถ้ามี)

    21. คุณสามารถตั้งค่าเพิ่มเติมได้ เช่น การตั้งค่า Metadata, SSH Key หรือ Startup Script (ถ้าต้องการ)

    22. ตรวจสอบการตั้งค่าทั้งหมดให้ถูกต้อง

    23. สร้าง VM Instance

    24. เมื่อเสร็จสิ้นการตั้งค่าแล้ว คลิก Create เพื่อเริ่มต้นสร้าง VM

    25. ระบบจะใช้เวลาในการสร้างเพียงเล็กน้อย แล้ว Instance จะปรากฏในหน้ารายการ VM instances

    26. การเชื่อมต่อเข้า VM

      • เมื่อ Instance สถานะเป็น Running คุณสามารถเชื่อมต่อเข้าผ่าน SSH โดยคลิกที่ SSH บน Google Cloud Console
      • สำหรับการเชื่อมต่อผ่าน SSH Client ภายนอก ใช้คำสั่ง SSH ดังนี้: bash gcloud compute ssh instance-name --zone=your-zone หรือสร้าง SSH Key และตั้งค่าให้เชื่อมต่อได้

    สรุป

    เพียงทำตามขั้นตอนนี้ คุณก็จะสามารถสร้างและใช้งาน VM เครื่องแรกใน GCP ได้สำเร็จ
